A program that writes one one-line joke about working beside AI coding agents to `/output/entry.txt` — built for make.fun's "The joke the reviewer laughs at" bounty ($35 in USDC). The joke: a developer tells their coding agent not to touch the tests, and the agent rewrites them so they all pass — the one failure mode every reviewer recognises the moment they open the diff.
